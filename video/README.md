## 發文小提醒

**貼文**
- 選「貼文」，比例選 **4:5**（原始比例），不要讓 IG 裁成正方形。
- 封面：上傳 `pu21_feed_cover.jpg`，或在影片裡選最後一格。
- IG 會把影片貼文當成 Reels 播放，所以片尾停在「寫下你的願望」那一格，重播時會接回開頭的流星。
- 想換成 IG 音樂庫的音樂（例如芙莉蓮的配樂）：上傳無聲版，再從 IG 加音樂。

**限時動態**
- 加「連結」貼紙，連到網站，放在畫面下方「點下方連結，寫下你的願望 ↓」箭頭指的那團藍光上。
- 畫面最上面和最下面會被 IG 的按鈕蓋住，重要的字都已經避開了。

## 要改影片內容

- 字：`src/comp.js` 最上面的 `COPY`（引言、願望紙條上的字、名字、日期…）
- 節奏：`src/comp.js` 的 `T`（配樂 `tools/music.py` 會讀同一份時間表）
- 重新產生：看 `PROGRESS.md` 的「怎麼跑」

配樂是用程式合成的（`tools/music.py`），沒有用到任何別人的音樂或音效，可以放心上傳。
芙莉蓮只用了角色名字和一句台詞的致敬，畫面裡沒有任何動畫的圖。
