# 影片進度（給接手的 Claude / 自己看）

目標：IG 宣傳影片兩個版本，約 15 秒，中文（繁體），芙莉蓮 / 欣梅爾主題，引導大家點連結去網站寫願望。
- 貼文：1080×1350（4:5）
- 限時動態：1080×1920（9:16），下方留位置放連結貼紙
- 各有「有配樂」和「無聲」兩版 + 貼文封面圖

## 怎麼跑
```bash
cd video && ./setup.sh                        # 裝工具、下載字型、開 http server、算權杖 3D 圖
node tools/render.mjs feed --stills 1,8.6,14.5  # 某幾秒的截圖 → build/stills/
node tools/render.mjs feed                    # 整支 → build/feed_silent.mp4
node tools/render.mjs story
python3 tools/music.py                        # 配樂 → build/music.wav（讀 build/timeline.json）
python3 tools/finalize.py                     # 合成 → out/
```
